The magic of Prince[cite: 1]

Prince is a computer program that converts XML and HTML into PDF.[cite: 1] It is simple, yet very powerful, and it creates beautiful documents.[cite: 1] The purpose of this small document is to showcase the formatting magic Prince can do.[cite: 1] We have chosen to highlight eighteen of our favorite features.[cite: 1] This document is written in HTML and converted to PDF by Prince.[cite: 1] The source file is a compact 13k document, including the embedded CSS, SVG and MathML.[cite: 1]

#1: Hyphenation[cite: 1]

Prince 6 supports automatic hyphenation which can break words across several lines, adding a hyphen at the word break.[cite: 1] Hyphenation is controlled with a set of experimental CSS properties, and hyphenation patterns for different languages can be supplied.[cite: 1] Notice how the text in this document is hyphenated.[cite: 1]

#3: Character substitution[cite: 1]

It's sometimes convenient to replace one character with another without changing the source document.[cite: 1] For example, the apostrophe character is easily found on keyboards, but in print it's common to replace it with a quotation character.[cite: 1] Notice how Prince 6 has replaced the apostrophes in this paragraph.[cite: 1]

#4: HTTP support[cite: 1]

Prince 6 has built-in HTTP support and can fetch pages, images, DTDs and style sheets from the web.[cite: 1] The image to the left was automatically fetched when the PDF version was generated.[cite: 1]

#5: Web fonts[cite: 1]

Prince 6 can fetch fonts from the web and use them without installing them on your system.[cite: 1] The fonts used in the PDF version of this document are web fonts.[cite: 1] We are grateful to Ray Larabie, Dieter Steffmann, and Red Hat for making hi-quality fonts freely available.[cite: 1]

#6: Image resolution[cite: 1]

Sometimes images should be scaled to a certain resolution, rather than to an absolute size.[cite: 1] In Prince, you can set the resolution of an image as a property in the style sheet.[cite: 1] The smiley face in the previous section was scaled this way.[cite: 1] The smiley also represents the challenging Acid2 test, which Prince 6 passes.[cite: 1]

#7: Columns[cite: 1]

Columns are commonly used on paper and Prince supports multi-column layouts described in CSS.[cite: 1] This document is laid out in two columns.[cite: 1] Also, this section uses a two-column layout with gap and a rule between.[cite: 1] The width of the gap and the style of the rule is set in the style sheet.[cite: 1]

#8: CMYK colors[cite: 1]

Printers don't use RGB colors, they mostly use CMYK: cyan, magenta, yellow and black.[cite: 1] Prince 6 can read CMYK colors and will use them, if present.[cite: 1] The heading above this paragraph has both an RGB color (red) and a CMYK color (bluish).[cite: 1] Therefore, the text is red in browsers, but blue in the PDF version.[cite: 1] This is for demonstration purposes; normally the colors would be close to each other.[cite: 1]

#9: Counters[cite: 2]

If you are reading the XHTML source code of this document, look for the h2 elements.[cite: 2] You will notice that they contain the text of the headings, but not their number.[cite: 2] The list item number, including the "#" and ":" are automatically generated by the style sheet.[cite: 2] Generated content and counters are especially useful for complex documents.[cite: 2] They are described in CSS level 2.1.[cite: 2]

#10: Crop and cross marks[cite: 2]

In printing, crop marks are used to indicate where the printed paper should be cut.[cite: 2] Cross marks are used to align prints of different colors to improve color reproduction.[cite: 2] Prince 6 adds support for crop and cross marks, and the PDF version of this document includes both.[cite: 2]

#11: Cross-references[cite: 2]

Prince can read hyperlinks inside a document and generate page numbers accordingly.[cite: 2] For example, it will automatically find out which page Headers and Footers are discussed on (page 2).[cite: 2] Cross-references are used to generate the Table of contents (page 1).[cite: 2]

#13: Footnotes[cite: 2]

Footnotes¹ are essential in printed documents and Prince knows how to generate them.[cite: 2] Unlike what some people think, footnotes are not the place to put information you don't want to see.[cite: 2] More often, footnotes will actually attract attention.[cite: 2] 9 of 10 of readers will read the footnotes before they read the text from where the footnotes are anchored.²[cite: 2]

#14: Leaders[cite: 2]

Leaders consist of dots or dashes in a row leading the eye across a page.[cite: 2] For example, the Table of contents has leaders in it.[cite: 2] The leaders are not found in the document itself, but rather in the style sheet.[cite: 2]

#15: SVG[cite: 2]

Scalable Vector Graphics (SVG) is a language for describing two-dimensional graphics for the web.[cite: 2] SVG images scale better than traditional bitmapped images and are suitable for printing.[cite: 2] The crown is generated by two SVG elements.[cite: 2]

#16: Page floats[cite: 2]

On paged media, elements can be set float to the top or bottom of pages.[cite: 2] The big URL at the top of this page comes after this paragraph in the source code, but is floated to the top by the style sheet.[cite: 2]

#17: Headers and footers[cite: 2]

Printed documents often have page headers and footers.[cite: 2] For example, page numbers are often printed at the bottom of the page, and the document title is shown at the top except on title pages.[cite: 2]

#18: PDF Bookmarks[cite: 2]

Prince will automatically generate PDF bookmarks from heading elements in HTML.[cite: 2] The feature is set with a property in the style sheet, and can also be used with other markup languages.[cite: 2]
